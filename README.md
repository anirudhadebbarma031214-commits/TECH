# NXT Browser — ANI STUDIO

A dark-themed starter desktop browser for Windows, built with Electron and Chromium.

## Features
- Multiple tabs and URL/search bar
- Back, forward, reload and home controls
- Quick links for Google, YouTube, GitHub and Wikipedia
- Ctrl+L, Ctrl+T and Ctrl+W shortcuts
- GitHub Actions workflow builds a Windows installer

## Get the EXE
1. Open the Actions tab in this repository.
2. Select Build NXT Browser for Windows and click Run workflow.
3. Open the completed workflow run.
4. Download the NXT-Browser-Windows-Installer artifact.
5. Extract the ZIP and run NXT-Browser-Setup-1.0.0.exe.

The EXE is generated by the workflow; it is not committed to the repository.

## Build locally
Install Node.js 20 or newer, open a terminal here and run npm install, then npm run dist. The installer is saved in release/.

## Limitations
This is a starter browser, not a complete Chrome replacement. Bookmark persistence, extensions, sync, ad blocking and private browsing are not implemented.
